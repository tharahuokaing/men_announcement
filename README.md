# 🌐 Huokaing Thara Bank & ISP Portal

Welcome to the official repository for the **Huokaing Thara Bank & ISP** corporate and executive announcement portal. This project features an immersive, cyberpunk-inspired Matrix digital rain background, automated multi-language executive speech synthesis, and secure operations management tools.

## ✨ Key Features

* **Matrix Hologram Background:** A custom canvas-based streaming digital text animation featuring corporate keywords.
* **AI Voice Presentation Engine:** Built-in multi-language speech synthesis (`km-KH` and `en-US`) to dynamically read official executive decrees and announcements with a live visualizer.
* **Interactive Countdown Timer:** Tracks the target timeline leading up to the grand opening.
* **Live Telemetry Broadcast Feed:** Real-time simulated log updates showing key executive assignments and security initialization routines.
* **Security Shielding:** Client-side protective handlers to disable default context menus and developer shortcut keys.
